Skill prostego języka

Upraszcza treści po polsku. Pomaga w pracy. Uczy pisać prosto.

Czym jest

Skill działa na dwa sposoby:

  1. Instrukcja dla agenta AI
  2. Prompt do wklejenia w czacie.

Bierze checklistę prostego języka i stosuje ją do Twojego tekstu. Nie zastępuje Cię. Daje propozycję.

Skąd pomysł

Checklistę i Fiszki Prostego Języka stworzyłyśmy w 2022 roku. Czasy się zmieniły: zasady pozostały te same, ale zmienił się nasz sposób pracy. Aby dopasować narzędzie do tego, jak pracujemy teraz, stworzyłyśmy narzędzia AI.

Są tu po to, aby Cię wspierać – nie zastępować w myśleniu. Odpowiedzialność za treści leży po Twojej stronie. Narzędzia to tylko asystent.

Checklista i fiszki uczą zasad. Skill robi z nich narzędzie do pracy w Cursorze, Claude Code i innych, podobnych aplikacjach.

Jak działa

Skill ma 4 główne tryby:

Tryb 1

Uprość

Dostajesz prostszą wersję i krótkie „co zostało zmienione”.

Tryb 2

Sprawdź

Audyt checklistą: cytat, reguła, propozycja. Na końcu pytanie, czy chcesz przykładową przepisaną wersję.

Tryb 3

Naucz

Jedna fiszka. Mini-ćwiczenie. Na końcu feedback.

Tryb 4

Napisz od zera

Agent dopyta: kto czyta, co ma zrobić, jaki jest kanał komunikacji. Gdy odpowiesz, wygeneruje swoją propozycję.

Zanim skorzystasz

Pamiętaj, że odpowiedzi narzędzia to tylko sugestie. Mogą Ci pomóc w pracy i nauce, ale nie zawsze są poprawne. Zawsze weryfikuj odpowiedzi AI.

Jak zainstalować

ChatGPT, Gemini i inne czaty bez skilli

  1. Otwórz prompt albo skopiuj go przyciskiem poniżej.
  2. Wklej jako instrukcję niestandardową, custom GPT albo pierwszą wiadomość.
  3. Potem wklej tekst albo napisz, czego potrzebujesz.
Otwórz prompt.md

prompt.md jest samowystarczalnym plikiem.

Cursor

Skill osobisty. Działa we wszystkich projektach:

git clone https://github.com/kalinatyrkiel/skillprostegojezyka.git ~/prosty-jezyk
mkdir -p ~/.cursor/skills/prosty-jezyk
cp ~/prosty-jezyk/SKILL.md ~/prosty-jezyk/checklist.md ~/prosty-jezyk/fiszki.md ~/prosty-jezyk/examples.md ~/.cursor/skills/prosty-jezyk/

Albo skopiuj cały folder do ~/.cursor/skills/prosty-jezyk/.

Skill tylko w jednym projekcie: te same pliki w .cursor/skills/prosty-jezyk/.

W Cursorze możesz napisać: „użyj skilla prosty język” i wkleić tekst.

Claude Code

mkdir -p ~/.claude/skills/prosty-jezyk
cp SKILL.md checklist.md fiszki.md examples.md ~/.claude/skills/prosty-jezyk/

W projekcie: .claude/skills/prosty-jezyk/ z tymi samymi plikami.
