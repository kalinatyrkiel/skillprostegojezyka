# Grafiki do social mediów

Pliki w tym folderze pasują do wizualnego stylu strony (karty z obwódką, kolorowe kafelki, Playfair + sans).

| Plik | Rozmiar | Gdzie |
|------|---------|--------|
| `feed-1200x1200.png` / `.svg` | 1200 × 1200 px | LinkedIn i Facebook (post kwadratowy, uniwersalny feed) |
| `story-1080x1920.png` / `.svg` | 1080 × 1920 px | Instagram / Facebook Stories |

Źródła wektorowe (`.svg`) możesz edytować w Figma lub Inkscape. PNG wygenerowane przez `@resvg/resvg-js-cli`.

Strona skillu: https://kalinatyrkiel.github.io/skillprostegojezyka/

Materiały źródłowe (checklista i fiszki): https://tiny.cc/ProstyJezyk
